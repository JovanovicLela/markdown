# Markdown project

### Description
A full-stack document management application built with Java, Spring Boot, Angular, TypeScript, and MongoDB. The system is organized into separate authentication and document services, with JWT-based security, permission-controlled access, REST API communication, and a dedicated Angular frontend.

### Overview
Markdown is a full-stack web application for managing users and documents through a modular architecture consisting of two Spring Boot backend services and an Angular frontend.
The application separates authentication and user management from document-related functionality, allowing each part of the system to handle a distinct responsibility.

The project consists of three main modules:

* **Auth Service** – authentication, authorization, and user management
* **Document Service** - document-related operations and application logic
* **Frontend** - Angular / TypeScript client application
